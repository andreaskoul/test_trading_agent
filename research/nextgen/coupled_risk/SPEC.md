# Mathematics and reproducibility — risk extension (2026-11-22)

Let `f_t` be a k-vector of *factor daily log returns* and `RV_t=sum_{intraday slots j} f_{t,j} f_{t,j}^T` an intraday realized covariance matrix. The origin uses data through `t-1`; the next 5 trading days are scored without updating the forecast inside the window. PCA loading basis `L_t` and POET residual covariance `D_t` are fitted only on `lookback=252` earlier daily rows.

**Covariance map:** `Sigma_{t+1|t}=L_t H_{t+1|t} L_t^T+D_t`; `D_t` uses off-diagonal soft threshold `1.5 sqrt(log(N)/T) sqrt(D_ii D_jj)` plus PSD projection. There is no future-data eigenbasis smoothing.

1. **Matrix HEAVY:** `H_{u+1}=(1-a-b)*mean(RV)+a*RV_u+b*H_u`, `a,b>=0`, `a+b<1`, estimated with Gaussian quasi likelihood `1/2(log det H + f'H^{-1}f)`. PSD by convex combination. This is a practical multivariate HEAVY-style recursion, not the most general matrix-HEAVY specification.
2. **DCC:** marginal variance `v_{u+1}=.05*vbar + .15*diag(RV_u)+.80*v_u`; standardized factor daily returns `z_u=f_u/sqrt(v_u)`; `Q_{u+1}=(1-a-b)*Qbar+a*z_uz_u' + b*Q_u`, normalized to `R=diag(Q)^{-1/2}Qdiag(Q)^{-1/2}`. Forecast `H=diag(sqrt(v)) R diag(sqrt(v))`. Estimate a,b by causal Gaussian quasi-likelihood. Diagonal variance coefficients are fixed baseline; correlation dynamics are fitted.
3. **Robust t-score covariance:** `H_{u+1}=(1-a-b)S + a*[.5*RV_u + .5*c_u f_u f_u'] + b*H_u`, `c_u=(nu+k)/(nu-2+f_u'H_u^{-1}f_u)`, `nu=7` fixed. This is a robust observation-driven covariance recursion, not full Fisher-information-scaled GAS.
4. **Coupled particle SV:** latent `h_u=mu+phi*(h_{u-1}-mu)+epsilon_u` with `epsilon~N(0,Q)` and non-diagonal `Q`; observation `f_u|h_u ~ Student_t(nu=7,C_u)` where `C_u=diag(exp(h_u/2)) R0 diag(exp(h_u/2))`, R0 estimated from earlier training. Sequential importance weights use exact conditional Student likelihood and systematic resampling each step. Nine pre-fixed `(phi, noise scale)` configurations are Bayesian-model-averaged by their approximate SMC log evidence. Multiple particle streams use fixed seeds, return effective sample size diagnostics. This joint model has stochastic factor volatilities but *constant conditional factor-return correlation R0* within the fitting window; the DCC model supplies the separate changing-correlation alternative.
5. **Predictive targets:** `V^real_{t:t+5}(w)=sum_{u=t+1}^{t+5}(w' r_u)^2`, `V^pred=5*w' Sigma_t w` (log-return approximation, no transaction costs). Loss `QLIKE=Vreal/Vpred-log(Vreal/Vpred)-1`; samples overlap, hence HAC. No candidate chooses its own test dates. Optional MASTER-ranked risk proxy is explicitly not a verified production fund return.

Models use no current-market data source, network, broker activity, or post-2019 labels. Current-constituent survivorship may bias evaluation; fixing that requires a historically correct holdings and name panel. No observed model gain is an observed net fund return.
