Returns are price returns before costs, signed for shorts. P&L = signed shares × (exit or current − entry), using actual fills at trade boundaries. One row per lot: a name held for a week, split where a daily review changed the shares. SPY rows are the market hedge. Invested = gross capital in positions at the day's close (long + short, shares × entry price); return on invested = account P&L since the first trade ÷ that day's invested amount.
